A tiny Python program (standard library only, no network) that writes a single number — the honest count of open browser tabs — to `/output/entry.txt`. The count is 87: research, coursework and half-read articles across a few windows. High enough to surprise, low enough to believe, and odd and non-round the way a real counted total looks.

> 87

The entry is one number, 2 characters, within the 1–5 character limit.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
